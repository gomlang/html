The fixed reference vectors in `reference.goml` were generated once from Go 1.26 standard-library `html.EscapeString` and `html.UnescapeString`. They preserve the former example FFI comparisons (all ASCII escapes, numeric values 0–1023, boundary numeric syntax, named entities and malformed/long inputs). Runtime tests use only GoML. Intentional numeric parsing differences continue to use separately stated expectations in `main.goml`.
